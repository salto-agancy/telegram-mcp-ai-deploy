# Sharing and community access

The source repository is public. Users clone it without collaborator access:

```bash
git clone https://github.com/salto-agancy/telegram-mcp-ai-deploy
```

Contributors work from a public fork and submit Pull Requests. Direct write or admin access
is unnecessary and should remain limited to maintainers. No clone contains an operator's
credentials, Telegram session, ACL or production configuration.

See [CONTRIBUTING.md](../CONTRIBUTING.md) and
[PROMPTS/CONTRIBUTE_WITH_AI.md](../PROMPTS/CONTRIBUTE_WITH_AI.md).
